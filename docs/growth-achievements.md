## 统计与历史追认

- 等级、已收获作物、已完成配方、现有设施、传送门和船只直接读存档，可追认。
- 远航总次数与累计物产读既有存档，不要求物品还在仓库。收集成就使用固定物品 ID 清单，未来扩池不提高门槛。
- 航线覆盖记录从新版本领取航次时累积；可额外追认存档中最后一次已领取航次，不能从航线解锁状态推断完成过哪条航线。
- 湿地记录领取过的任务和该任务产物；畜牧记录实际领取的物品。旧库存不能证明获得来源，不据此补历史。
- 鸭苗在结算确认孵出时记录，羊羔在成功配种生成时记录；购买动物不计入繁育。更新时仍在孵化中的鸭蛋后续孵出也计入。
- 探秘战斗胜利单独记录；逃跑不算胜利。副本通关还要求本趟确实击败 BOSS、路线完成并返程结算，失败或提前撤离不算。红枫林腹地要求全程完成并返程。
- 新统计字段都有空默认值；沿用 schema v31，旧档无需整体改写。不修改已领取成就记录，也不重发旧奖励。
