## 待办

### 1. 肥料槽与厩肥（原第六节的一半）

畜牧这批只做了饲料槽。肥料槽整块推迟，因为它要改**已上线的农作开工流程**（6.3 的开工一次性预扣），跟当时「外放时勿修改已有界面」的约束冲突。

- `items` 增加 `fertilizer` 配置块，字段结构与 `feed` 一致（`units` / `score`）
- 新物品 `manure` 厩肥（material、售价 2、**无品质**）：每当任一动物完成一个产出周期，设施 `manure_pending += 1`（禽）/ `2`（哺乳），上限 = 容量 × 6，满则停止累积，且**不影响畜产品的溢出上限**
- 农作开工时按 `⌈基础生长时长(小时) × 作物 fertilizer_rate⌉` 一次性预扣，不够也能开工，按覆盖率 `r` 给比例加成，空槽 `r = 0` 照常开工
- 前端：`SlotPanel` / `SlotDepositDialog` 已经是通用组件，肥料槽直接挂第二个实例即可，不需要新写面板

## 实装时改过的口径

以下与设计文档不一致，**以这里为准**：

| 文档写的 | 实际做的 | 原因 |
| --- | --- | --- |
| 首批物种鸡 / 羊 / 兔 | 鸡 / 奶牛 | 羊毛→布、兔皮→皮革那条线跟第三里程碑的探索装备一起排 |
| 产出周期 4h / 12h / 6h | **全物种恒为 8h** | 周期不受任何能力影响，是畜牧最干净的一条心智模型 |
| 散养地周期 +25% | 同样 8h | 同上；散养地的劣势只留容量 2、品质系数 ×0.8、溢出 2 周期 |
| 设施品质修正 −20 | 品质**系数** ×0.8 | 亲密度改乘算之后，负数 Q 乘 1.2 方向会反 |
| 亲密度进品质 `+0.25/点` | 乘算 `0.95 + 0.0025 × 亲密度` | 亲密度是放大已有底子，不是一份固定加分 |
| 照料推进当前产出周期 | 只给亲密度和经验 | 周期是硬常量，加速会把离线定位打回去 |
| 散养地走失判定 | 砍掉 | 纯负反馈，散养地已经有三重劣势 |
| 退役阶段 | 砍掉，换成手动**出售动物** | 回收价随基因走，换代压力照样在，少一套状态 |
| 幼崽是背包物品 | 直接在设施卡上购入，不进背包 | 幼崽必须落进具体栏位、当场掷基因、校验容量 |
| 品质在收取时掷 | **在结算的每个周期当场掷** | 否则倒一槽精饲料再收取会追溯提升已经攒下的产出 |

另外两条是文档没写、实装时定下的：

- 攒满溢出上限的牲畜**不产出也不吃料**，但它的**配种冷却照走** —— 否则忘了收产出会把冷却一起冻住
- 饲料槽由鱼塘和畜栏**共同结算**：两边先各自报需求，再按同一个比例拿预算，槽的品质分在扣料之前取快照
