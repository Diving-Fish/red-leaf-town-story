# 旧港出海：首版内测

出海在居民 16 级开放。仅 `RED_LEAF_TOWN_BETA_PLAYERS` 白名单玩家可访问业务接口，入口只编入 `--beta` 前端，路径 `/red-leaf-town-beta/aquatic?tab=sailing`，旧 `/red-leaf-town-beta/sailing` 链接自动跳转。内测水产页分为钓鱼、鱼塘、出海三个 Tab，切换时保留编队与补给选择；桌面侧栏使用三列图标按钮。正式构建继续使用原有水产页和列表导航，出海仍受后端白名单保护。内测与正式服共用存档；首版物产明确排除出每日委托池。

## 可体验内容

- 初帆号首次需要建造：10000 红叶币＋20 个复合木板＋1 块远航风帆，即刻完成，不额外消耗体力。镇民工坊 16 级开放复合木板配方，每份消耗 2 枫木板＋2 月银矿，2 体力、基础 60 秒，产出 1 板。建造优先消耗低品质，重复请求不重复扣费。
- 一艘船，最多三名不同伙伴，至少一名即可出发。
- 芦苇海湾 2 小时；完成一次航行开放白帆渔场（6 小时），完成三次开放雾灯群岛（10 小时）。不再要求提高居民等级。
- 每个角色第一次航行为 60 秒试航，消耗 20 红叶币、1 体力，基础抽取降为 1 次；首次领取后永久恢复标准航程。额外补给仍按正常成本扣除，试航推荐基础补给。
- 基础补给免费；口粮、鱼饵、维修物资三选一，使用现有腌萝卜、精饲料、枫木板，优先消耗低品质。首版补给品质不额外放大效果。
- 普通航线采用水产能力，群岛采用探索能力；最高能力伙伴贡献全部，其余贡献 25%。产业有效等级上限仍生效。能力通过与探索相同的饱和曲线增加抽取次数。
- 自动事件使用现有四维属性，选择队伍里对应调整值最高的伙伴掷 d20，难度 12，自然 1 / 20 必失败 / 成功。现已接入 `sailing_prepare` 伙伴特性阶段，凡妮莎的「循星引航」提供全船事件＋2及每趟一次首败优势重掷，成功另加一次物产抽取。对应产业天赋能力在航行出发时加算一次。
- 航海见闻册记录成功事件和累计带回的物产；保留上次完整航海日志。
- 货舱、渔具各可改装三级，分别增加抽取次数和稀有海产权重；升级前必须领取本次航行。
- QQ `红叶镇出海` 可查看相同的等级、内测资格与航行状态，并提供内测页面入口；编队和领取在 Web 完成。

## 持久化与事务

存档 schema v31 增加 `sailing`，旧存档迁移时默认空状态。新增 `ship_built` 默认未建造；缺少该字段、但已有航行或改装记录的旧存档保留船只。未造船不能出航或改装。每次出航通过 repository 原子更新校验、扣费和移动伙伴，保存带规则版本的航行快照：时间、能力、成本、实际消耗的品质桶、改装等级、奖励、经验与事件检定。出航之后升级伙伴或修改内容配置不会重掷本次结果。尚未到港时 API 不返回奖励和日志。

出海伙伴纳入公共任务锁，航行期间不能派驻生产、陪钓或开始探索；已在探索中的伙伴不能出海。抽离鱼塘、畜栏继续遵守既有换班窗口与预约规则。出航会清掉陪钓与原有生产派驻；到港按服务器时间自动解除锁，未领取不延长占用。

领取通过原子更新入库、增加居民与伙伴经验、登记见闻和航次。使用航行 ID 拒绝错领，最后一趟重复领取不再发奖。出航保留最近 50 个请求 ID 防重；改装使用期望等级防止重复升级。

## 数值定位与后续

当前是体验数值：标准航行居民经验为每点体力 6，伙伴经验沿用工作时长与体力口径。长航普通产物的每小时基础产量低于短航，通过独有产物和离线便利补偿。稀有物产当前仅能收藏或出售，尚未加入新配方、灯塔建设、第三座传送门与收藏奖励；这些要在确认出海循环后继续扩展。

自动化覆盖等级与白名单、参数错误、原子回滚、首次试航、航线解锁、任务占用、冻结结果、防重领取、改装、HTTP 接口，以及隔离 Redis 键下的跨服务重载领取。浏览器验收使用独立内存角色，不修改真实玩家存档。

## 扩充物产与数值验收

三条航线各 18 种产出：12 种普通海产、3～4 种稀有物产、1～2 种树果种子和一件独有探索装备。普通与稀有海产集合全局不重叠。千香果种子来自芦苇海湾/雾灯群岛，椰木果种子来自白帆渔场/雾灯群岛；种子不在商店出售。所有新物品延续内测物产规则，排除每日委托。

树果命名参考宝可梦的[千香果](https://wiki.52poke.com/wiki/千香果（道具）)（减弱水属性攻击）和[椰木果](https://wiki.52poke.com/wiki/椰木果（道具）)（从大海漂来）。种植复用现有树果曲线。

基础抽取次数分别为 6 / 14 / 18，能力加成上限 40%、难度 60。所有掉落复用探索的 draw_count 与 draw_weighted_batches，按单池有放回抽取，重复物品合并。成功事件增加抽取次数，风浪失败减少已累积额外次数；货舱每级加基础次数的 10%，口粮加 20%；渔具每级加稀有海产权重的 40%，鱼饵加 75%。种子不受稀有海产权重加成。装备动态权重使首次获得期望维持 250 体力（非保底），不因抽取加成或试航变便宜。规则版本 3 只用于新航次，已出航的旧奖励照常领取。

运行 `python scripts/sailing_yield.py` 重建[完整收益验算](sailing-yield.md)。基础含种植收益约 52～86 币/体力，满改装与最优补给约 82～122；与现有钓鱼/采矿同数量级。验算包含船费、补给出售机会成本、种植体力和品质、装备出售收益；不计一次性改装与时间机会成本。

造船属于一次性资本投入：按普通品质复合木板售价 360 估值，加上普通品质远航风帆 9738，共 26938 红叶币机会成本。收益表的币/体力是建成后的持续经营口径，不包含此项；总净收益另减 10000 币与实际消耗的 20 板及 1 帆价值。复合木板每份原料基础售价 268，加工增值 92 / 2 体力 = 46 币/体力，与既有工坊曲线一致。
