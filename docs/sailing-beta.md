# 旧港出海：首版内测

出海在居民 16 级开放。仅 `RED_LEAF_TOWN_BETA_PLAYERS` 白名单玩家可访问业务接口，入口只编入 `--beta` 前端，路径 `/red-leaf-town-beta/aquatic?tab=sailing`，旧 `/red-leaf-town-beta/sailing` 链接自动跳转。内测水产页分为钓鱼、鱼塘、出海三个 Tab，切换时保留编队与补给选择；桌面侧栏使用三列图标按钮。正式构建继续使用原有水产页和列表导航，出海仍受后端白名单保护。内测与正式服共用存档；首版物产明确排除出每日委托池。

## 可体验内容

- 一艘船，最多三名不同伙伴，至少一名即可出发。
- 芦苇海湾 2 小时；完成一次航行开放白帆渔场（6 小时），完成三次开放雾灯群岛（10 小时）。不再要求提高居民等级。
- 每个角色第一次航行为 60 秒试航，消耗 20 红叶币、1 体力，基础收获降为 1 件；首次领取后永久恢复标准航程。额外补给仍按正常成本扣除，试航推荐基础补给。
- 基础补给免费；口粮、鱼饵、维修物资三选一，使用现有腌萝卜、精饲料、枫木板，优先消耗低品质。首版补给品质不额外放大效果。
- 普通航线采用水产能力，群岛采用探索能力；最高能力伙伴贡献全部，其余贡献 25%。产业有效等级上限仍生效。能力增加普通收获和稀有发现率。
- 自动事件使用现有四维属性，选择队伍里对应调整值最高的伙伴掷 d20，难度 12，自然 1 / 20 必失败 / 成功。首版不接入伙伴特性管线。
- 航海见闻册记录成功事件和累计带回的物产；保留上次完整航海日志。
- 货舱、渔具各可改装三级，分别增加普通收获和稀有发现率；升级前必须领取本次航行。
- QQ `红叶镇出海` 可查看相同的等级、内测资格与航行状态，并提供内测页面入口；编队和领取在 Web 完成。

## 持久化与事务

存档 schema v31 增加 `sailing`，旧存档迁移时默认空状态。每次出航通过 repository 原子更新校验、扣费和移动伙伴，保存带规则版本的航行快照：时间、能力、成本、实际消耗的品质桶、改装等级、奖励、经验与事件检定。出航之后升级伙伴或修改内容配置不会重掷本次结果。尚未到港时 API 不返回奖励和日志。

出海伙伴纳入公共任务锁，航行期间不能派驻生产、陪钓或开始探索；已在探索中的伙伴不能出海。抽离鱼塘、畜栏继续遵守既有换班窗口与预约规则。出航会清掉陪钓与原有生产派驻；到港按服务器时间自动解除锁，未领取不延长占用。

领取通过原子更新入库、增加居民与伙伴经验、登记见闻和航次。使用航行 ID 拒绝错领，最后一趟重复领取不再发奖。出航保留最近 50 个请求 ID 防重；改装使用期望等级防止重复升级。

## 数值定位与后续

当前是体验数值：标准航行居民经验为每点体力 6，伙伴经验沿用工作时长与体力口径。长航普通产物的每小时基础产量低于短航，通过独有产物和离线便利补偿。稀有物产当前仅能收藏或出售，尚未加入新配方、灯塔建设、第三座传送门与收藏奖励；这些要在确认出海循环后继续扩展。

自动化覆盖等级与白名单、参数错误、原子回滚、首次试航、航线解锁、任务占用、冻结结果、防重领取、改装、HTTP 接口，以及隔离 Redis 键下的跨服务重载领取。浏览器验收使用独立内存角色，不修改真实玩家存档。
