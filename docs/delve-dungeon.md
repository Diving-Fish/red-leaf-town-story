# 探秘副本（delve）

探索产业的第二类路线。采运（`transport`）保持原样：纯体力换材料、无战斗、一到三人。探秘（`delve`）
在同一套逐节点引擎上加了 HP、装备和回合制战斗，终点是首领。两类路线共用同一个 run 槽位，
同时只有一支队伍在外。

## 一、灰度与外放

探秘先在内测站验收，之后随「灵果草甸」一起外放：路线上的 `beta: true` 已经摘掉，武器的加工配方
也按当时的约定跟着外放一起补进了 `data/game.json`。现在正式站就能看到这条路线，内测期间用来发
装备的镇邮局（`/red-leaf-town/admin/mail` 个人信附件）不再是必需路径。

灰度机制本身保留着，下一批内容照用：

- 路线上的 `beta: true` + 环境变量 `RED_LEAF_TOWN_BETA_PLAYERS`（逗号分隔的 `player_id`）
  决定谁能看到、谁能进。非白名单玩家在快照里根本看不到这条路线，直接打 start 接口也会被拒。
- 内测前端是 `./build-front.sh --beta` 产出的 `frontend/dist-beta`，由 Quart 的
  `/red-leaf-town-beta/` 路由发出，和正式站 `frontend/dist` 互不影响；两站共用后端、Cookie 和存档。
- 注意正式站的产物是 `./build-front.sh`（构建 `frontend/dist` 并同步到 `/var/www/html/red-leaf-town/`）。
  内容外放的同时要重新构建一次正式站，否则线上跑的还是没有副本界面的旧包。

## 二、出发准备

固定三人满编，领队仍然必须具有探索倾向（队伍探索能力公式与采运一致）。出发时冻结两样东西：

- **装备快照**（`ExplorationRunState.loadout`）：每人一把武器 + 一件饰品，存的是数值不是 item_id。
  装备**不消耗**，出发后把原物品卖了也不影响这趟队伍，所以不需要任何库存占用逻辑。
  同一件装备不能同时装在多人身上（校验按仓库件数算）。
- **携带道具**（`carried_items`，最多 6 份）：出发时从仓库扣除，进副本后只能用带的这些，
  撤离时没用完的原样退回。物品要在 `items` 里写 `delve_use` 配置块才能带，
  与"没写 `feed` 就不能投料"同一口径。

## 三、战斗数值

公式集中在 `src/red_leaf_town/domain/delve_battle.py` 顶部，调平衡只改那里。

| 项 | 公式 |
| --- | --- |
| 最大 HP | `24 + 2×伙伴等级 + 2×力量 + 装备 max_hp_bonus` |
| AC | `10 + 敏捷调整值 + 装备 armor_bonus` |
| 先攻 | 开场一次 `d20 + 敏捷调整值 + 装备先攻`，定序后整场固定，平手我方优先 |
| 命中 | `d20 + 武器属性调整值 + attack_bonus + proficiency_bonus` vs 敌人 AC；自然 1 必失 |
| 暴击 | 骰面 ≥ `20 - clamp(幸运调整值, 0, 2)`，伤害骰数翻倍、加值不翻 |
| 伤害 | `武器骰 + 武器属性调整值`；没带武器按徒手 `1d4` |
| 属性调整值 | `(属性 - 10) // 2`，沿用 `ExplorationStats.modifier` |
| 逃跑 | 全队敏捷取最高做一次 `d20` 检定对 `flee_dc`，失败白丢一个回合 |
| 战利品品质 | 队伍最高幸运调整值 × 8，走既有的 `quality_ability_bonus` 通道 |

武器分三类，分别吃力量（赤铜大剑 1d10）、敏捷（月银短剑 1d6，命中和先攻更好）和智力
（枫火之书 1d8）。饰品给熟练加值、护甲、生命、先攻或**每场一次的优势骰**。装备不进五档品质，
一件装备就是一组固定数值。

## 四、流程与失败

- 战斗节点**不推进深度**：选择带 `battle` 的行动时照常扣体力（战斗本身不再扣），建立战斗状态；
  打赢之后才结算这一节点 `success` 里的奖励、深度 +1 并抽下一层。逃跑成功同样推进一层，但没有奖励。
- 玩家的每一次行动（攻击 / 用道具 / 屏息取优势 / 逃跑）之后，服务端会一口气把后面的敌方回合
  跑到下一个我方回合或战斗结束，一次请求返回这一段日志。
- HP 在副本内不自然回复，只能靠道具；一趟结束（撤离、走完或全灭）恢复满。
- **全灭**只损失冻结的战利品（品质产物和装备类掉落一起清空），装备不消耗、伙伴不受伤、不锁定。
- 战斗进行中不能撤离。体力见底时这趟路线原地挂着等自然回复，副本不会结束。

## 五、内容结构

- `exploration_expeditions[].kind = "delve"`，事件里的选择可以带
  `battle: {enemy_ids, can_flee, flee_dc}`。`battle` 与 `check` 互斥，且只允许出现在 delve 路线上。
- 顶层 `delve_enemies` 定义敌人（HP / AC / 先攻 / 若干次攻击 / `boss` 标记）。
- 装备是 `kind: "equipment"` 的物品，必须带 `equipment` 块且 `has_quality: false`。
  加工是唯一允许产出无品质物品的产业：配方的产物只要是装备就跳过「必须支持品质」这条校验，
  掷出来的品质在 `_resolve_output` 里统一收敛到 0 号格，所以装备只会落在仓库的无品质格里。
- 装备类掉落写在结局的 `fixed_rewards` 里（不进品质系统），品质产物仍写 `rewards`。
- 无品质的物品（装备、种子）只能进 `fixed_rewards`；有品质的产物只能进 `rewards`，内容加载时两边都会校验。

首条路线「灵果草甸」：10 级、2500 红叶币、8 层。草甸深处长着魔力树，产物是
**柔韧牧草**（主）、**银星苔**、**秋露草**，外加两种树果的种子——桃桃果种子和莓莓果种子在别处买不到，
这条路线是它们唯一的来源。结构是 3 类遭遇战 + 荆藤木桩 + 牧人旧棚（幸运检定摸饰品）+
魔力幼树（两条种子分支），终点是果心守望者（88 HP / AC 15 / 两种攻击），
击杀保底给一枚猎人护符和一颗桃桃果种子。

种子的出处刻意分开：桃桃果种子来自垂果灌丛大成功、魔力幼树的摘果分支和 BOSS 保底；
莓莓果种子只出在魔力幼树，主要靠「连根起那株莓莓」这条智力 DC16 的分支。
魔力幼树在一趟里的出现率约 54%，所以莓莓果种子大致每三四趟才见一颗。

## 六、武器的来源

三把武器都在镇民工坊锻造，10 级解锁，每次 5 体力、10 分钟：

| 配方 | 原料 | 产物 |
| --- | --- | --- |
| 锻造赤铜大剑 | 赤铜矿 ×20 | 赤铜大剑（力量，1d10） |
| 锻造月银短剑 | 月银矿 ×10 | 月银短剑（敏捷，1d6，命中和先攻 +2） |
| 装订枫火之书 | 枫木 ×10 + 红枫树脂 ×3 + 琥珀蜂蜡 ×1 | 枫火之书（智力，1d8，命中 +1） |

三把武器的售价统一压到 200，低于自身原料价：锻造是给副本准备装备的，不是一条卖钱线，
所以 `test_crafting_prices_reflect_inputs_and_mining_stamina_value` 把装备配方从售价考核里摘了出去。
饰品目前仍然只从副本里掉（牧人旧棚和 BOSS），没有配方。

## 七、验证基线

`scripts` 之外用等级 10、三件武器 + 一件饰品、4 份上品药膏的队伍跑 20 趟满编通关：
全清 20 / 20，平均剩余 HP 50%，最低 17%。同样的队伍**不带任何装备**再跑 20 趟：
只清了 8 趟，12 趟全灭。也就是说装备是这条路线的实际门槛，等级和四维只是底子。
一趟通关的期望产出约 54 份柔韧牧草、10 份银星苔、6 份秋露草、1.1 颗桃桃果种子、
0.3 颗莓莓果种子，加上必掉的猎人护符。
