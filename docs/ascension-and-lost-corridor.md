# 一破、失落回廊与分段经验曲线

2026-09-14 实装。完整配方见 [51 名角色材料表](partner-ascension-review.md) 和 [TSV](partner-ascension-review.tsv)。材料表保留当时的预算模型；实际规则以本文和配置为准。

## 一次突破

居民达到15级、伙伴达到20级后开放。一破等级上限40，二破尚未配置。51个角色ID均按原始稀有度配置成本，升星不会提高突破费用：

| 原始稀有度 | 奇迹结晶 | 红叶币 |
|---|---:|---:|
| 三星 | 12 | 5000 |
| 四星 | 15 | 6500 |
| 五星 | 18 | 8000 |

每名角色另需一项上品及以上产业物产，以及少量不限品质特色物品，数量和物品沿用审阅表。奇迹结晶不分品质，不能在商店购买，售价0，并从日常委托池排除。装备型特色物品会被消耗，界面明确提示。

服务端在一次原子更新中结算旧状态、校验居民等级与伙伴等级、扣钱、从最低合格品质开始扣材料，再提高突破阶段并结算已积累经验；材料或钱不足时不会部分扣除。重复请求因没有二破配方而被拒绝。已有任务的伙伴、品质与时间快照不会变化。

七个产业的有效等级上限同步提高到40；生产、探索和航海仍受伙伴自身突破阶段上限限制。等级带来的能力提升随培养逐步生效，一破不会直接赠送40级能力。现有资产生产继续按分段快照结算。

伙伴页通过姓名旁的「培养」按钮打开弹窗，将升级、突破、升星整合为同级标签页，共用培养面板风格；经验书先选择再使用，复用数量选择器支持单次 1～99 本（不超过库存）；升级页根据后端下发的逐级经验门槛，实时预览当前与使用后的等级、经验及满级留存经验，突破标签展示材料与准备进度，弹窗提供目标立绘、等级上限、40级能力预览、符合品质要求的库存和钱币需求。桌面为立绘/材料两栏，移动端改为紧凑立绘头部和单列材料，确认按钮固定在弹窗底部；成功后留在新形态展示页。复用全站的深绿、叶色、金色、品质标签与通用弹窗。

当前配置中小星陨、泽非羊的 `artworks` 为空；配方已配置，培养可以完成，但插画显示待补充状态，未替这两名角色编造或生成素材。

## 经验曲线

伙伴当前等级L升至下一级的经验：

- 1≤L<20：`40 + 15×(L−1)`。
- 20≤L：`350 + 140×(L−20)`；当前只开放到40级，二破未开放。

| 阶段 | 经验 |
|---|---:|
| 1→10 | 900 |
| 10→20 | 2425 |
| 1→20 | 3325 |
| 20→30 | 9800 |
| 30→40 | 23800 |
| 20→40 | 33600 |

配置使用 `partner_growth.level_cost_segments`，从指定起始等级覆盖基础曲线，校验分段起点唯一递增、边界经验需求不回落。旧存档的等级、剩余经验和满级后溢出经验原样保留，不按新总经验重新降级；历史schema迁移仍使用旧版本公式。经验书经验值、售价与工作经验规则保持原值。

## 失落回廊

- ID：`lost_corridor`；类型 `delve`；居民15级开放，无beta限制。
- 三人满编，门票1000币；每人可带武器和饰品，全队最多带6件治疗道具。
- 六层；1～2层从外层池随机取，4～5层从内层池随机取，每个具体事件每趟最多出现一次。
- 第3层唯一候选「外层结晶室」是固定精英；第6层由 `final_event_id` 固定为「奇迹之泉」BOSS。

| 事件 | 抽取权重 | 奖励 |
|---|---:|---|
| 外层碎晶虫巢／内层深层虫巢 | 各3 | 两只碎晶甲虫；树脂1 |
| 外层巡逻石卫／内层沉默哨站 | 各3 | 一只回廊石卫；赤铜矿1 |
| 外层噬光蛾群／内层微光苔庭 | 各3 | 两只噬光飞蛾；银星苔1 |
| 外层废弃营地／内层遗落行囊 | 各1 | 药膏1、小本同行札记1 |
| 内层残存书库 | 2 | DC13智力检定，成功小本2、失败小本1 |
| 第3层外层结晶室 | 固定 | 击败结晶守卫：奇迹结晶1 |
| 第6层奇迹之泉 | 固定 | 击败奇迹守望者：奇迹结晶2、厚册同行札记2 |

普通物产使用现有探索品质规则，书和结晶使用固定奖励，不受物产数量加成影响。营地取得的药膏属于待结算战利品，不能在本趟立即使用；携带治疗仍应在出发前准备。

每层路途体力2，普通事件行动体力2，精英/BOSS行动体力3。全程路途原始体力12、行动14，实际体力为 `14 + ceil(12×(1−探索减耗率))`。测试队伍均为24，能力较低时可能25～26；没有检定失败附加体力。前三层只得1结晶，走完全程得3枚及500经验书，深入比反复中途撤离更有效率。

保底奖励在**打赢之后**才进入暂存战利品，最终须在探索界面选择完成路线并返程后入库。战斗中不能撤离；全灭丢失尚未带回的结晶、书及其他战利品。装备、伙伴与没用完的原携带道具沿用现有探秘规则。固定精英和BOSS不能战斗逃跑。

## 验证

- 全角色配方核对：51个ID、原始稀有度费用、特色物品、产业物品与数量符合审阅表。
- 校验15级/20级门槛、合格品质计数和扣除顺序、扣费原子性、重复突破、溢出经验与任务快照。
- 抽样100组随机路线，验证事件池有变化且3/6层始终固定。
- 新本流程验证：精英后撤离得1结晶、全通得3结晶和2厚册、入库之前库存不变、全灭不发结晶、重复结算不重复发奖。
- 实际敌人数值模拟：白凛/古剑喵/雅兹薇尔，以及雾剑/小哈/红凯，两组均20级未突破，带按自身最高攻击属性选择的现有武器、无饰品/天赋，携带6份上品秋露药膏；血量低于45%时使用药膏，其余行动集中攻击一个敌人。每组固定种子0～39，各40/40通关；平均用药0.90/2.55份，平均主动操作75.9/87.8次，体力均24。该结果是这两组队伍的抽样，不是所有阵容必胜保证；完整体力预算之外，实际应另计药膏准备成本。

最终验收：720项测试全部通过；前端类型检查与生产构建通过。使用本机内存测试存档及本地立绘样本，在1440×1000、768×1024、390×844、320×740下检查页面与弹窗无横向溢出、确认按钮可见；验证成功展示、低品质库存不计入需求、禁用提交，浏览器运行时异常为0。平板宽度下原有顶部经验条改为自动换行。
