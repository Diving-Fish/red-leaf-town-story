# 垂钓收益基线

调数值时的参照表：每个钓点在四档水产能力下的**体力 → 金币**期望。表是 `scripts/fishing_yield.py`
按线上内容算出来的，改完 `data/game.json` 重跑一遍就是新表：

```bash
venv/bin/python scripts/fishing_yield.py
```

## 口径

- 金币 = 售价 × 品质倍率的期望。品质走钓点自己的品质曲线（阈值 30/60/110/200，宽度 18），
  倍率是 1.0 / 1.2 / 1.5 / 2.0 / 3.0，所以**能力同时抬高数量和单价**，两头复利。
- 抽取次数 = `⌊(基础次数 + 0.1 × 聚鱼度) × (1 + 能力加成 × A/(A + 难度)) + 0.5⌋`，跟着能力和聚鱼度一起涨。
- 一竿只挂一条大物：抽中的第一条进入搏鱼、当竿不结算，多抽到的按退回的普通鱼计入。
  所以下表的「每轮金币」**不含**大物本身，大物单列。
- 聚鱼度取两个端点：0 层（换点或久不下钓）和 10 层（满层，天赋可以再加 5 层）。
- **杂物按售价计，是低估**。鱼苗（3 金）真正的价值是鱼塘里长出来的成鱼，水草和杂鱼真正的
  价值是饲料槽的品质分。这张表只回答"直接卖掉能拿多少"，是收益下界。
- 经验固定 6 点/体力，两个钓点都一样，表里不再重复。

## 几条观察

1. **搏一把在任何能力档下都比多抛一竿划算**（小溪 48–89 对 35–114，红叶湖 99–160 对 50–131），
   而且低能力时优势最大。这符合设计意图：大物是演出和图鉴触发，不是要玩家算的决策点。
   反过来说，如果哪天想让"放线"成为真选择，要动的是成功率而不是奖励倍率。
2. **能力从 0 到 120，每点体力的金币大约翻三倍**（小溪 35 → 114，红叶湖 50 → 131），
   因为抽取次数和品质倍率同时在涨。伙伴等级上限 20 级压着的就是这条曲线 —— 现阶段单人满配
   约 A = 141，正好在表尾附近。
3. **红叶湖对小溪的领先随能力收窄**：A = 0 时每体力高 42%，A = 120 时只高 15%。
   小溪的抽取次数难度更低（120 对 150），能力堆上去之后次数涨得更快。想拉开后期钓点的差距，
   要么抬稀有鱼的价，要么调 `draws.difficulty`。
4. 聚鱼度满层大约值 **+20% ~ +30% 的每体力收益**，代价是不能换点。这个幅度足以让"攒体力集中
   打一个点"成为默认打法，但不至于让换点变成错误操作。
